# Conceptual figures for chapters 3 and 4

Four teaching figures were added. Each is introduced before its float and followed by prose explaining the mathematical implication. Every original equation block and citation remains intact. The figures contain hypothetical component states and procedural logic, with no simulation observations, model rankings, learning curves, or measured timings.

| Figure label | Assets | Mathematical purpose and prose integration |
|---|---|---|
| fig:reactor_reaction_accounting | article/figures/ch3_concept_reaction_accounting.tex and PDF export | Connects the 2A-to-B and B-to-2C example to individual process changes and the inventory weights 1,2,1. It precedes the scalar reaction-rate equations. The following paragraph explains why the middle pool's net change depends on both rates while each process preserves inventory. |
| fig:reactor_feasible_triangle | article/figures/ch3_concept_feasible_triangle.pdf, SVG, and PNG | Displays the weighted-inventory plane through cA/cB coordinates with cC recovered from 11-cA-2cB. It marks all three nonnegative vertices, the influent anchor, the worked state, and an inventory-consistent state with negative pool B. The following paragraph interprets the boundary pools and why inventory does not identify kinetics. |
| fig:relative_projection_geometry | article/figures/ch4_concept_weighted_projection.pdf, SVG, and PNG | Shows inverse-concentration ellipses, the conserved sum-four line, raw/provisional point, anchor, relative-weighted candidate, and equal-absolute-weight candidate. It follows the full small-number minimization and precedes the general least-squares objective. The following paragraph explains different first-contact points under different distances. |
| fig:projection_acceptance_flow | article/figures/ch4_concept_projection_flow.tex and PDF export | Separates positive-target construction, conservative correction, positivity shortening, and final numerical acceptance. It includes a failure branch and shared audit. The following paragraph explains why neither provisional positivity nor an algebraic equality alone establishes final-state acceptance. |

The two plot families are generated by .codex-work/plot_reactor_concepts.py using the isolated numpy/matplotlib environment. They use embedded serif fonts, white backgrounds, dark lines, distinguishable marker shapes, and a restrained blue accent. Equal-absolute versus relative weighting is distinguished by dotted versus solid contours as well as color.

Both TikZ assets compile independently through the standalone wrappers under .codex-work/reactor-diagram-proof. Diagram text uses locally fixed line spacing so that the book's surrounding line spacing cannot make boxes overlap. Standalone PDFs were copied into article/figures as reviewable vector artifacts. The main manuscript uses the native TikZ assets directly.

Visual inspection checked plot labels, markers, contour tangency, diagram spacing, and arrow direction. Initial overlapping diagram text was corrected before finalization. The worked triangle state and influent anchor each have weighted inventory eleven. Original mathematical arithmetic and equation preservation checks continue to pass.
