8.5   Equipment and Software
For this research, an NVDIA GeForce RTX 4090 graphics card is needed so that the
manifold of computations carried our herewith are performed fast, especially during the
model calibration and simulation phases detailed previously. Furthermore, all of the code
in this study is developed using Python as programming language. The pyomo library is
used for implementing all optimization models and are all saved as Mathematical
Programming System (mps) files. On the other hand, the sklearn library is used for the
implementation of the common ML techniques.
The High-performance parallel linear optimization software (HiGHS) algorithm is used to
solve all linear optimization models, while the Interior Point Optimizer (Ipopt) algorithm is
used to solve all nonlinear model models.
