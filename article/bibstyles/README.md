The dissertation uses `apacite_dissertation.bst`, a local derivative of
`apacite.bst`. It retains the apacite reference format and uses the first
author followed by *et al.* in citations with three or more authors.
Two-author citations retain both names.

The original `apacite.dtx` and `apacite.ins` files accompany the style under
the LaTeX Project Public License specified in their headers.
